# GeoSmart

Personal geoscience portfolio for Camila Fernández.

## First steps

1. Install Node.js (LTS): https://nodejs.org/
2. Open Terminal in this folder.
3. Run:
   npm install
   npm run dev
4. Open the local address Astro gives you, usually http://localhost:4321

The project is intentionally beginner-friendly. We will replace the placeholder text, images, CV, email and domain together.

## Structure

- `src/pages/` = website pages
- `src/components/` = reusable pieces such as the logo
- `src/styles/` = visual design
- `public/` = files such as images and PDF CV
